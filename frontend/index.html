Projects

Azure Cloud Resume & Serverless Architecture

The Azure Cloud Resume is a production-grade, event-driven web application designed to demonstrate end-to-end cloud engineering capabilities. Hosted on Azure Static Web Apps with custom DNS routing via GoDaddy, the frontend communicates with a serverless Python backend (Azure Functions) and a NoSQL Cosmos DB database to power a live visitor counter. To showcase event-driven architecture, the site features a decoupled contact form that drops payloads into an Azure Storage Queue, which instantly triggers an Azure Logic App workflow to process and dispatch secure email notifications.

Beyond the application code, the entire environment was built with a DevSecOps and automation mindset. The underlying infrastructure is fully coded and managed using Terraform, implementing lifecycle rules to prevent state drift, ensuring the architecture is reproducible and immutable. All updates are routed through an automated GitHub Actions CI/CD pipeline, guaranteeing that every commit is automatically analyzed for security vulnerabilities via CodeQL before being deployed to the live production environment.

Serverless Secret Management Platform

The Serverless Secret Management Platform is a "Zero-Trust" credential vault engineered to securely generate, store, and manage user passwords. Originating as a local vanilla JavaScript application, it was completely re-architected into a globally hosted, serverless application deployed on Azure Static Web Apps. The frontend interfaces with a Node.js-based Azure Functions API, utilizing Azure Table Storage as a highly scalable and cost-effective NoSQL database for data persistence. To guarantee hardware-backed security, the system leverages Azure Key Vault to securely hold sensitive hashes, such as the Master PIN, completely removing them from the application code.

Emphasizing security and automation, the entire cloud environment is codified using Azure Bicep for Infrastructure as Code (IaC). This declarative approach handled complex dependency graphs and Role-Based Access Control (RBAC) orchestration, automatically generating a Managed Identity for the Static Web App. By utilizing platform-native Key Vault References to fetch secrets dynamically during runtime, the architecture successfully eliminates all hardcoded credentials. The result is a highly secure, reproducible cloud environment built entirely on strict identity-based access controls.
